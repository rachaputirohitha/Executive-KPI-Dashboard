# Executive KPI Dashboard – Power BI

##  Project Overview

This project is an **Executive KPI Dashboard** created using **Power BI** as part of Task 26 in the Data Analytics Track at VEDA Technology.

The dashboard provides a concise one-page view of key business performance indicators and allows users to interact with the report using dynamic filters.

##  Objective

The main objective of this project is to design a management-level dashboard that helps users quickly understand business performance through KPIs, trends, comparisons, and interactive visualizations.

##  Tools & Technologies

- Power BI
- Power Query
- DAX
- Superstore Dataset

##  Key Features

- Executive-level KPI cards
- Total Sales analysis
- Total Profit analysis
- Order/transaction performance
- Profitability analysis
- Sales and profit trends
- Category/segment analysis
- Regional performance analysis
- Top-performing products
- Interactive slicers and filters
- One-page management dashboard

##  Dashboard Components

The dashboard includes:

### KPI Cards
- Total Sales
- Total Profit
- Total Orders
- Profit Margin / Growth KPI

### Visualizations
- Sales & Profit Trend
- Sales by Category
- Regional/Segment Performance
- Top Products by Sales
- Profit by Segment
- Comparative performance charts

### Filters

Interactive filters are provided to allow users to analyze the dashboard based on different business dimensions such as:

- Region
- Segment
- Category
- Date/Year

## Key Insights

The dashboard helps management identify:

- Overall sales and profitability performance
- Sales and profit trends over time
- High-performing categories and segments
- Regional performance differences
- Top-performing products
- Areas requiring further business attention
